# Malik Usman Super Store

A simple website for Malik Usman Super Store, a village general store. Customers pick items and send their order on WhatsApp.

- Fresh dhoodh and dahi, kurkure, toffees and biscuits
- Home delivery available
- Open 6:00 AM to 10:00 PM
- WhatsApp: +92 309 9836597

Open `index.html` in a browser to see the website.
